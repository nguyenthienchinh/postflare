# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback gracefully, and focus on
what is best for the community. Harassment, insulting or derogatory comments, personal or political attacks, and
publishing others' private information are not acceptable.

The standards apply in all project spaces (issues, pull requests, discussions) and when representing the project
elsewhere.

## Enforcement

Report unacceptable behavior privately to the maintainer through
[GitHub Security Advisories](https://github.com/FerdiKT/postflare/security/advisories/new) or by contacting the
maintainer on GitHub ([@FerdiKT](https://github.com/FerdiKT)). Reports are handled confidentially. Maintainers may
remove, edit or reject contributions and temporarily or permanently ban contributors who do not follow this code, as
described in the [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
