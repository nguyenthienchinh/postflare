The first public release of **Postflare**: a self-hosted social media scheduler that runs entirely on Cloudflare
(one Worker, D1, R2, Workflows and Images) and fits the **Workers Free plan**. No servers, no Docker, no Postgres/Redis.

Live demo: https://postflare.ferdi.app/demo (sandboxed, never publishes, reset daily).

## Highlights

- **36 platforms**: X, LinkedIn (profiles and pages), Facebook Pages, Instagram, Threads, YouTube, TikTok (and TikTok
  for Business), Pinterest, Reddit, Bluesky, Mastodon, Tumblr, Telegram, Discord, Slack, WordPress, Medium, DEV,
  Hashnode, Nostr, Farcaster, Lemmy, Google Business Profile and more, plus a generic Webhook.
- **Composer, calendar and media library**: per-account text and settings with live limits, threads and first comments,
  previews, drafts; month/week calendar with drag to reschedule; media on R2 with multipart uploads up to 5GB, streamed
  to the platforms without buffering.
- **Reliable publishing** with Cloudflare Workflows: retries, processing checks (videos, Instagram, TikTok), follow-ups,
  and a cron that recovers anything lost and refreshes tokens. **No double posts**: when a platform doesn't confirm a
  post, it goes to "Needs check" instead of being retried blindly.
- **Playbooks**: 20 research-backed recipes (with sources) that AI agents follow to write posts, searchable over MCP and
  the CLI; posts remember the playbook and A/B variant they used, and a ranking shows which playbooks perform best on
  your accounts. Workspaces can write their own.
- **Analytics**: post metrics (views, reach, engagement...) collected 1h, 24h, 3d, 7d and 30d after publishing, and daily
  follower counts.
- **Teams**: users, workspaces, built-in and custom roles, invite links.
- **For agents and scripts**: REST API with per-workspace API keys, a built-in MCP server (`/mcp`), the
  [`postflare` CLI](https://www.npmjs.com/package/postflare) (`npm i -g postflare`) and a Claude Code skill.
- **Upload links**: one-time pages to send media from a phone (or from an AI chat's sandbox).
- **Optional live demo mode** for public instances, and an **Admin overview** of usage and Free plan quotas.
- **Meta data deletion callback** and a deletion status page, ready for Meta app review.
- **Security hardening**: tokens encrypted at rest (AES-GCM), CSRF protection, login throttling, optional `SETUP_TOKEN`,
  strict CSP, workspace isolation on every query, API keys without instance permissions.

Full list: [CHANGELOG.md](https://github.com/FerdiKT/postflare/blob/v0.1.0/CHANGELOG.md).

## Install

- **One click**: [Deploy to Cloudflare](https://deploy.workers.cloudflare.com/?url=https://github.com/FerdiKT/postflare)
  creates the Worker, D1 database, R2 bucket, Workflow and Images binding, and a copy of the repository in your GitHub
  account that Workers Builds deploys on every push.
- **From a clone**:
  ```bash
  git clone --branch v0.1.0 https://github.com/FerdiKT/postflare.git && cd postflare
  npm ci
  npx wrangler login
  npm run deploy
  ```

Then open the URL, create the first user (instance admin) and connect your platforms. Setting the `SECRET_KEY` secret
before connecting accounts is recommended. See the [README](https://github.com/FerdiKT/postflare#installing).

## Upgrade notes

First release: nothing to migrate. From now on, updating is deploying the new code; database migrations run
automatically on the first request. See [Updating](https://github.com/FerdiKT/postflare#updating). Instance admins see
new releases in the app (Admin → Instance settings), and copies made with the Deploy button get a weekly update pull
request from the included `Postflare update` workflow.

## Known limitations

- Platform integrations are covered by tests against **mocked platform APIs**; only **Instagram**, **TikTok**, **X** and
  **YouTube** have been exercised against the real APIs so far. Please [report](https://github.com/FerdiKT/postflare/issues) anything that
  breaks with a real account.
- **TikTok** apps that have not passed TikTok's audit can only post privately ("Only me"), and **YouTube** projects that
  are not verified upload private videos. Make them public in the app afterwards, or get your app reviewed.
- **X**: posting and reading metrics need a paid X API plan (or credits).
- Analytics need extra permissions on some platforms (see the README's Analytics table); existing accounts must be
  reconnected to grant them.
